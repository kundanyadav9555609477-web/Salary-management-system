# Salary Management System

A simple and clean Employee Salary Management System built with HTML, CSS, JavaScript and Java backend logic.

### 🚀 Live Demo
Deployed on GitHub Pages

### ✨ Features
- Add employee details (Name, ID, Department)
- Calculate Gross Salary, Deductions (PF, Tax)
- Calculate Net Salary automatically
- HRA (10%), DA calculation
- View all employees in a table
- Dark and modern responsive UI

### 🛠️ Tech Stack
- Frontend: HTML, CSS, JavaScript
- Backend Logic: Java (SalaryCalculator.java)
- Version Control: Git & GitHub

### 📂 Project Structure
- `index.html` - Main UI
- `style.css` - Styling (Dark Theme)
- `script.js` - Salary calculation logic
- `SalaryCalculator.java` - Java backend logic

### 📸 How it Works
1. Enter Employee Name and Base Salary
2. Click Calculate
3. System calculates HRA, Gross, Deductions and Net Salary
4. Employee added to the list below
